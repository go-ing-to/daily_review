하루 돌아보기 2.0 웹 앱 (PWA)

아이폰 Safari에서 HTTPS로 공개된 주소를 열고 공유 > 홈 화면에 추가 > 웹 앱으로 열기를 활성화합니다.
아직 호스팅되지 않은 소스 파일입니다. ZIP을 풀고 index.html, defaults.js, manifest.json, sw.js, icon.png를 동일한 사이트 폴더에 업로드하세요. 예: 무료 GitHub Pages 공개 저장소의 main 브랜치 루트에 파일을 업로드하고 Settings > Pages > Deploy from a branch > main / (root) > Save. 사이트 주소가 생성되면 Safari에서 열고 지인에게 링크를 공유할 수 있습니다. 모바일 화면에서 Settings 메뉴가 안 보이면 데스크탑 웹 사이트 요청을 사용하세요.

기록은 각 사용자 기기에 localStorage로 저장되며 서버로 전송하지 않습니다. 다른 사람과 기록을 공유하지 않습니다. 삭제/브라우저 데이터 삭제 시 기록이 사라질 수 있으니 백업을 권장합니다. JSON 백업은 이 웹 버전용으로 네이티브 앱 백업과 호환되지 않습니다. 백업은 평문입니다.

제공 기능: 고정 3개 탭, 기본 20문항, 체크 상태/비고, 날짜 이동, 주간/월간/연간 통계, 항목 추가/수정/삭제/순서 변경/반복 요일, 감사일기, 기도 제목/응답, 수동 JSON 백업/복원, CSV, 인쇄를 통한 PDF 저장. HTTPS에서 서비스 워커 설치 후 오프라인 이용을 지원하도록 구성했습니다.

웹 버전 제한: 자동 예약 알림과 자체 Face ID 잠금은 지원하지 않습니다. 아이폰 미리 알림의 매일 반복으로 대체하거나 생성한 ICS 파일을 캘린더에 가져와 알림을 확인하세요. PDF는 Safari의 인쇄/공유 기능을 이용하며 실제 기기에서 확인해야 합니다. 네이티브 버전에는 로컬 알림과 Face ID/기기 암호 잠금 소스가 포함됩니다.

검증: JavaScript 구문 검사 및 기본 데이터/날짜/통계 테스트. 실제 아이폰 실행 및 공개 배포는 미완료.
